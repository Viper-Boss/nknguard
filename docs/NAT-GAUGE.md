# NAT 映射仪表盘

NAS 面板和 Android 使用同一套红黄绿分区、缓动指针与中文状态。灰色表示未连接、没有足够的 STUN 结果或面板状态失联；灰色不代表最差网络。

刻度从左侧红色到右侧绿色，指针越向右表示映射条件越有利于尝试直连。

当前探测对同一个 UDP 套接字查询不同 STUN 目标，观察映射是否变化：

| 测量结果 | 显示 | 指针 |
| --- | --- | --- |
| 公网观察地址与本地套接字地址一致 | 公网 · 无地址转换 | 绿色 |
| 多目标得到相同外部映射 | 映射稳定 | 青绿 |
| 外部映射随目标变化 | 映射随目标变化 | 红色 |
| 没有足够结果 | 尚未测定 | 灰色 |

这些是映射条件提示，不是带宽、延迟分数，也不证明公网入站可达。传统的全锥型、地址受限锥型、端口受限锥型和对称型在 UI 中作为参考说明；稳定映射不能单独区分前三种，不能直接显示成“全锥型”。地址相关的映射变化表示对称型映射特征，但当前探测也未区分地址相关和地址端口相关的详细行为。

准确的细分还需要支持行为发现的 STUN 服务和入站过滤探测。普通 STUN 服务不可用或超时也不等于运营商防火墙已被确认。映射观测不会决定是否跳过直连；IPv6、局域网、ICE 和中继分别依据实际探测与认证握手工作。

指针只在观测变化时缓动，不产生额外网络请求，不写入日志文件；系统关闭动画时直接显示目标位置。

依据：[RFC 4787 的映射与过滤术语](https://www.rfc-editor.org/rfc/rfc4787.html)、[RFC 5780 的 NAT 行为发现](https://www.rfc-editor.org/rfc/rfc5780.html)。
