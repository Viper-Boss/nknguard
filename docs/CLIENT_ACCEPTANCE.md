# 客户端完善与实机验收

## Windows 0.2.3-preview

- 提供当前用户安装包、开始菜单和系统卸载入口；升级保留用户配置。
- 未安装官方 WireGuard 时显示安装入口，并阻止直接申请连接权限。
- 根据实际后台状态展示缓存链路检查、信标获取、直连探测和中继建立；动画仅表示正在处理，不表示连接成功。
- 已验证链路提供“打开飞牛”和“复制 NAS IP”。浏览器默认打开 5666 端口，改过飞牛端口时请复制 IP 后自行填写。
- 诊断可在后台离线时导出，只读取配置与清理结果，不遍历身份密钥目录；包含网络地址，分享前仍应检查。
- Windows 状态文件被索引器等短暂占用时，对同一个替换动作最多重试一秒；不会先删除旧文件，持续失败仍明确报错。
- 卸载前必须从托盘退出。有 shutdown.json 的安装会再次请求管理员清理隧道；拒绝提权或清理失败会中止卸载。
- 配对资料默认保留于 `%LOCALAPPDATA%\NKNGuard`。永久删除前先在 NAS 撤销设备、完成清理，然后删除这个明确目录。官方 WireGuard 是共享依赖，不随本程序卸载。

安装器采用 Inno Setup 的[当前用户安装模式](https://jrsoftware.org/ishelp/topic_setup_privilegesrequired.htm)，卸载使用[等待进程退出及检查退出码](https://jrsoftware.org/ishelp/topic_isxfunc_exec.htm)。

## 已自动验证的范围

Windows CI：测试、编译、安装包构建；在隔离 runner 上静默安装、覆盖升级、卸载，并检查程序文件已移除。此检查不代替 UAC、真实隧道和已有用户资料的实机验收。

## 实机验收顺序

1. NAS 备份当前二进制及配置、状态目录到仅管理员可读的位置；不要将含私钥的备份上传 GitHub。记录原有服务路径，保留数据盘现有文件。
2. NAS 首次安装由用户设置管理密码，面板展示 NKN 地址和配对二维码；重启保留身份，不能每次重启都生成地址。
3. Windows 安装并完成六位码核对批准，复制虚拟 IP 在飞牛客户端访问文件。
4. 外网连接：同网、跨网、直连受阻转中继、恢复直连；验证文件传输而非仅看动画。
5. NKN 不在线时验证缓存直连及局域网面板可用；没有可用链路时必须继续显示连接中。
6. NAS 撤销设备后，已有通道失效；重启客户端不能重新获得授权。
7. Windows 取消 UAC、断开、异常退出后的重试清理；核对 WireGuard 服务、适配器和路由。
8. Windows 覆盖升级保留身份；卸载后清理隧道，默认仅保留明确列出的用户资料。拒绝 UAC 时应保留程序以便重试。
9. Android 真实手机验证 Wi-Fi/蜂窝切换、锁屏和进程重建。当前仍为 debug 签名，不能承诺跨 CI 包直接覆盖升级。
